# SemHash 文本对人工标注规范

## 标注目标
判断两条文本是否表达相同或实质相同的信息，而不是判断它们是否包含相同关键词。

## 标签
- `1`：重复。两条文本核心事实、对象和结论基本相同，仅存在措辞、语序或格式差异。
- `0`：不重复。两条文本表达不同事实，或关键对象、条件、时间、数值、结论存在实质差异。
- `uncertain`：信息不足或边界模糊，需要复核。

## 标注原则
1. 同义改写、语序变化、轻微格式变化，通常标为重复。
2. 主题相同但具体事实不同，标为不重复。
3. 数字、日期、地点、主体或否定关系改变且影响含义时，标为不重复。
4. 仅共享常见关键词，不足以判为重复。
5. 不确定时使用 `uncertain`，不要猜测。

## 推荐流程
1. 先独立阅读两条文本。
2. 先给出人工标签，再查看模型相似度分数。
3. 为边界样本填写备注。
4. 对 uncertain 样本进行二次复核。
5. 保留标注者、日期和数据版本。

## 质量控制
- 对部分样本进行重复标注。
- 统计标注分歧并讨论规则。
- 在实验报告中说明数据来源、样本数量和标注流程。
