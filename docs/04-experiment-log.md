**实验目的：** 初步验证 SemHash 的安装和语义去重功能。

**实验环境：**
- Python 3.10
- SemHash 0.5.0
- Windows PowerShell

**实验参数：**
- 相似度阈值：0.85
- 原始文本数量：8

**实验结果：**
- 保留文本：8

- 重复率：0.0

**结果分析：**

第一次实验中，所有文本均被保留，没有检测到重复文本。这说明当前实验数据和模型配置下，没有文本达到去重判定条件。

# 实验二：SemHash 相似度阈值对比实验

## 1. 实验目的

研究不同相似度阈值对 SemHash 文本去重结果的影响。

## 2. 实验设置

- 测试数据：10条英文文本
- 实验工具：SemHash 0.5.0
- 实验方法：调整相似度阈值
- 实验阈值：0.5、0.6、0.7、0.8、0.9、0.95

## 3. 实验结果

| 阈值 | 保留数量 | 过滤数量 | 重复率 |
|---|---:|---:|---:|
| 0.5 | 5 | 5 | 0.5 |
| 0.6 | 5 | 5 | 0.5 |
| 0.7 | 5 | 5 | 0.5 |
| 0.8 | 8 | 2 | 0.2 |
| 0.9 | 8 | 2 | 0.2 |
| 0.95 | 8 | 2 | 0.2 |

## 4. 实验观察

随着相似度阈值提高，过滤数量减少，说明阈值会影响文本去重的严格程度。

在本次测试数据中，阈值0.5至0.7时过滤5条文本，阈值0.8至0.95时过滤2条文本。

## 5. 初步结论

SemHash的去重结果对相似度阈值具有一定敏感性。后续需要通过人工标注测试集，结合Precision、Recall和F1-score进一步评价去重效果。
