# Experiment 05：细粒度阈值分析

## 1. 实验目的

研究 SemHash 在不同相似度阈值下的语义去重表现，
分析阈值对 Precision、Recall 和 F1-score 的影响。

## 2. 实验设置

- 数据量：10 条文本
- 测试阈值：0.68 至 0.84
- 阈值数量：10 组
- 评价指标：Precision、Recall、F1-score

## 3. 实验结果

在当前小样本实验中：

- 0.68 和 0.70 的 F1 均为 0.8889。
- 0.74、0.75 和 0.76 的 Precision 均为 1.0。
- 阈值达到 0.78 后，Recall 降至 0.5。

## 4. 初步分析

随着阈值提高，系统过滤重复文本的策略趋于保守，
Precision 提高，但 Recall 可能下降。

这说明单一相似度阈值难以同时兼顾误删和漏检问题。

## 5. 局限性

当前数据集仅包含 10 条文本，评价方式仍沿用初步记录级标注，
实验结果仅供探索，不能作为最终性能结论。

## 6. 下一步工作

构建更大规模的人工标注文本对数据集，
研究基于双阈值和人工复核的语义去重策略。
