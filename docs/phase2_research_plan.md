# SemHash 第二阶段研究计划

## 1. 阶段目标
在已完成的 SemHash 基础复现、阈值实验和双阈值实验基础上，建立更规范的文本对标注数据集，评估语义去重策略，并验证阈值校准与置信度分级是否能够改善去重效果。

## 2. 拟研究问题
1. 不同相似度阈值对 Precision、Recall、F1 有什么影响？
2. 单阈值与双阈值策略相比，是否能在保持准确率的同时减少人工复核量？
3. 置信度分级是否能更合理地区分自动判定与人工复核样本？

## 3. 实验设计
- 构建文本对数据集，记录每对文本的人工标签。
- 使用 SemHash 计算文本相似度。
- 在多个阈值下进行判定。
- 比较单阈值与双阈值策略。
- 统计 Precision、Recall、F1、自动判定比例、人工复核比例。
- 对错误样本进行分析。

## 4. 标注规范
- 1：两条文本表达相同或实质相同的信息，可视为重复。
- 0：两条文本表达不同的信息，不视为重复。
- 不确定：仅凭当前文本无法可靠判断，暂不纳入二分类指标，单独记录并复核。

## 5. 建议评价指标
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2 * Precision * Recall / (Precision + Recall)

同时报告自动判定覆盖率、人工复核率，以及各类别样本数量。所有指标应基于人工标注的文本对计算。

## 6. 实验注意事项
- 不要只使用极少量样本得出普遍性结论。
- 标注时尽量不要查看模型相似度分数，减少标注偏差。
- 对边界样本进行复核，并保留原始标注记录。
- 固定数据集划分和实验参数，确保结果可复现。
- 当前方案属于待验证的研究方向，不能在实验完成前宣称方法有效或具有已证实创新性。
